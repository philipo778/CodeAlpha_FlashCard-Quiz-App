# CodeAlpha Flashcard Quiz App

This project is developed as part of the App Development Internship program at **CodeAlpha** (Task 1: Flashcard Quiz App). It is a native Android application designed to help users study efficiently using interactive flashcards with local database persistence.

## 📱 Features & Requirements Met
- **Question & Answer Structure:** Each flashcard displays a question on the front and an answer on the back.
- **Show Answer Toggle:** Includes a dedicated button to smoothly flip and reveal answers using 3D property animations[cite: 1].
- **Navigation Controls:** Users can seamlessly navigate between cards using **Next** and **Previous** buttons[cite: 1].
- **Full Customization (CRUD):** Users can add new custom flashcards, edit existing questions and answers, and delete flashcards[cite: 1].
- **Persistent Storage:** Integrated locally using SQLite (`SQLiteOpenHelper`) to ensure user records and custom data are saved safely across sessions.
- **Clean User Interface:** Built with a simple, clean, and intuitive Material Design UI[cite: 1].

## 🛠️ Tech Stack
- **Programming Language:** Java
- **UI & Layout:** XML Layouts, Material Design Components, CardView, FloatingActionButton
- **Database:** SQLite (`SQLiteOpenHelper`)
- **Animations:** Android Property Animation API (`ObjectAnimator`)
